# 计算机体系结构学习计划 — 交接文档

> 用途：新对话 / 新 agent 快速接手上下文。直接通读本文件即可。

## 一句话背景

用户（HIT 博士，C++ 仅“能阅读”水平，能读懂 Verilog，**无**数字逻辑/OS/计算机组成底子）计划去中科院计算所学习 CPU 设计，走“一生一芯”（ysyx.org）官方路径（此路径为用户默认选择，未绑定具体课题组）。

## 已确认的决定（拷打/grilling 产出，均已获用户确认）

1. **目标与验收**
   - 近端验收：通过“一生一芯”预学习 + 预学习答辩
   - 远端验收：独立实现一个能跑的小 RISC-V 处理器（流水线 + 简单 cache），冲 A 阶段指标
2. **时间**：每周 10–15 小时，无硬性截止；预学习答辩约 3 个月；零基础到流片官方估算约 500 小时（8–12 个月）
3. **AI 使用边界**（用户选“推荐项”）
   - AI 可查概念、读报错、解释代码、生成片段；**不可整模块代写**
   - 合入 AI 代码前必须自己读懂，每周能无稿讲清自己写的每个模块
   - 每 1–3 天一条工作记录，AI 参与部分如实标注；“一生一芯”用 Git log + 工作记录跟踪进度并查重
4. **工具链**：预学习用 Verilog（材料最多）；A 阶段再决定是否切 Chisel；仿真用 Verilator / iverilog + GTKWave
5. **教学方式**：用户已全权委托 agent 排计划、定节奏、给验收标准

## 路线图（P0–P3）

| 阶段 | 时间 | 目标状态 | 主要内容 |
|---|---|---|---|
| P0 地基 | 第 1–2 周 | C 从“能读”到“能写” | 指针/内存/链表/文件 IO；200–300 行 C 小项目（哈希表或简化 malloc）；Git/Linux；数字电路概念速过（布尔代数、触发器、状态机）；ysyx.org 报名 |
| P1 预学习·硬件入门 | 第 3–8 周 | 单周期 RISC-V CPU 跑通 | Verilog 会写（ALU、寄存器堆、计数器、状态机）；RV32I 指令集；数据通路与控制器；仿真工具链；《CPU设计实战》+ 一生一芯讲义 |
| P2 预学习·收尾 | 第 9–12 周 | 五级流水线 + 简单 cache，过答辩 | 冒险检测、数据转发、分支处理、分支预测入门；cache；预学习总结与答辩 |
| P3 A 阶段 | 第 13 周起 | 完成 A 阶段指标 | 完整处理器 + cache + SoC 集成；组会汇报；决定是否切 Chisel |
