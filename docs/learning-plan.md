# 学习计划（12 周主线 + A 阶段）

每周 10–15 小时，无硬性截止，随到随学。预学习答辩约 3 个月；零基础到流片总量约 500 小时（8–12 个月）。

| 阶段 | 时间 | 目标状态 |
|---|---|---|
| P0 地基 | 第 1–2 周 | C 从“能读”到“能写”，Git/Linux 顺手，数字电路概念速过 |
| P1 预学习·硬件入门 | 第 3–8 周 | Verilog 从看懂到会写，单周期 RISC-V CPU 跑通 |
| P2 预学习·收尾 | 第 9–12 周 | 五级流水线 + 简单 cache，过预学习答辩 |
| P3 A 阶段 | 第 13 周起 | 完成 A 阶段指标（完整处理器 + cache + SoC 集成） |

## P0 地基（第 1–2 周）

- [ ] Linux 命令行 + Git 基本功（init/commit/log/branch）
- [ ] C 语言：指针、内存布局、链表、文件 IO
- [ ] 写一个 200–300 行 C 小项目（哈希表或简化 malloc）
- [ ] 数字电路概念速过：布尔代数、组合/时序逻辑、触发器、状态机
- [ ] 在“一生一芯”官网完成报名，开始预学习

验收：能独立写 C 程序并跑通；Git 仓库建立，开始每 1–3 天提交工作记录。

## P1 预学习·硬件入门（第 3–8 周）

- [ ] Verilog 从看懂到会写：ALU、寄存器堆、计数器、状态机
- [ ] 仿真工具链：Verilator / iverilog + GTKWave
- [ ] RV32I 指令集：指令编码、格式、语义
- [ ] 数据通路与控制器：从单周期开始
- [ ] 单周期 RISC-V CPU 跑通简单 C 程序
- [ ] 精读《CPU设计实战》对应章节 + 一生一芯讲义

验收：单周期 RISC-V CPU 在仿真中跑通；能无稿讲清自己写的每个模块。

## P2 预学习·收尾（第 9–12 周）

- [ ] 五级流水线：冒险检测、数据转发、分支处理
- [ ] 分支预测入门
- [ ] 简单 cache 设计（流片指标需要）
- [ ] 写预学习总结文档
- [ ] 提交预学习答辩申请，完成答辩

验收：通过“一生一芯”预学习答辩。

## P3 A 阶段（第 13 周起）

- [ ] 按官方讲义推进 A 阶段：完整处理器 + cache
- [ ] SoC 集成（决定是否切换 Chisel）
- [ ] 保持每周组会汇报 + Git log + 工作记录
- [ ] 达成 A 阶段指标，进入流片评估

验收：完成 A 阶段内容（官方口径到流片的门槛）。
